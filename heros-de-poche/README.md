# Héros de poche

Jeu de stratégie au tour par tour façon Heroes of Might and Magic, pour iPhone.

**Jouer :** https://jojojolyporc.github.io/petits-jeux/heros-de-poche/
Pour l'installer, ouvrir l'adresse dans Safari, puis Partager → « Sur l'écran d'accueil ».

## Règles
Prendre toutes les villes ennemies. Carte d'aventure, villes à développer, recrutement, combats tactiques sur grille hexagonale, campagne de sept scénarios (La Couronne du Dragon) ou partie libre (1v1 à 1v3). Les règles complètes sont dans le jeu : menu → Règles en bref.

## Sauvegarde
La partie et la campagne s'enregistrent sur le téléphone. Menu → Sauvegarde → « Obtenir le code de sauvegarde » donne un texte à garder dans Notes, rechargeable par « Charger un code de sauvegarde ».
